## Finding 1 — blocking (round 1 only, resolved before this record's diff), confirmed — unrebased
`TC-M0-20` regression

`mkr-code-reviewer`'s round-1 pass found that `tests/config_test.sh`'s `TC-M0-20` seed-config
leak-exclusion check, as it existed on this branch (forked before `main`'s PR #31), used a narrower
per-variable exclusion than the version PR #31 had since merged to `main` — PR #31's broader,
cross-variable exclusion exists specifically because two config variables' documented-enum comments
can share a word (`MKR_STOP_TEST_MODE` and `MKR_WORKTREE_POLICY` both use `"off"`). This diff never
touched `TC-M0-20` itself; the branch had simply not picked up `main`'s already-merged fix. Merging
as-is would have silently reintroduced that false-positive bug the moment it combined with `main`'s
`.mkr/config` (which now also sets `MKR_STOP_TEST_MODE="off"`).

**Fix:** rebased this branch onto the current `main` tip (`git rebase main`) — clean, no conflicts,
since this diff's own changes to `tests/config_test.sh` (two array entries) don't overlap
`TC-M0-20`'s lines. Commit `0178d3a` → `31f05c7`.

**How independently verified (round 2, not taken on the rebase's own success as proof):**
